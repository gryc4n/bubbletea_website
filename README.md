# Bubble Tea

A modern landing page for a fictional bubble tea brand, created to practice frontend development, UI design and responsive layouts.

> This is an ongoing project. New sections, interactions and improvements will be added as development continues.

## About the Project

Bubble Tea is a fictional bubble tea brand website designed with a modern, colorful and playful visual style.

The main goal of the project is to practice building a complete frontend interface from a custom design while improving my understanding of HTML, CSS and JavaScript.

The project focuses on:

- Modern UI design
- Responsive layouts
- Reusable components
- Interactive elements
- Visual consistency
- Clean frontend structure

---
